# 🚀 Welcome to the Software Engineering Hub

Welcome to the **Hub** — a centralized, interactive environment for learning programming through **structured lectures, guided labs, and hands-on exercises**.

This playground hosts **multiple programming tracks**, each representing a full course. All labs are **runnable directly in the browser**, with no local setup required.

---

## 🎯 How to Use This Playground

1. **Choose a Course Track**
   Use the navigation panel on the left to select an available course.

2. **Follow the Structured Flow**
   Each course is organized by weeks or topics, aligned with lectures and labs.

3. **Practice Actively**
   Write code, run it, inspect output, and iterate.

4. **Revisit Freely**
   You can return to any lesson or lab at any time.

5. **Ask Questions**
   Use the official communication channels listed below.
