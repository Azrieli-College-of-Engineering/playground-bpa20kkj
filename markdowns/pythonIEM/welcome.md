# 🐍 Python OOP (IEM) — Welcome

Welcome to the **Python Object-Oriented Programming (OOP)** course.

This course is designed for **Industrial Engineering & Management (IEM)** students and focuses on building **correct, structured, and maintainable software** using Python, as well as industry relevant libraries.

---

## 🎯 Course Goals

By the end of this course, you should be able to:

- Design and implement classes correctly
- Model real-world problems using OOP principles
- Use inheritance and polymorphism appropriately
- Write readable, testable, and maintainable Python code
- Understand *why* a design works — not just *how*
- Working with industry relevant Python libraries: numpy, pandas, matplotlib

---

## 🧭 How This Course Is Organized

- Content is divided into **chapters / topics**
- Each topic may include:
  - Explanations and examples
  - Interactive labs
  - Practice exercises
- Labs run **directly in the browser** — no setup required

Use the navigation panel to move between topics.

## 🧪 Labs & Practice

- Labs are meant for **learning and experimentation**
- Most labs are **not graded**
- You are encouraged to:
  - Modify code
  - Break things safely
  - Re-run and observe behavior

Always prioritize **lecture-aligned material** for exams and graded assignments.
